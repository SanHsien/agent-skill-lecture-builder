## Project Scope

This repository ships a Windows-first maintenance fork of `agent-skill-lecture-builder`. It provides a tool and Agent Skill to transform Markdown lecture manuscripts into standalone, responsive single-page HTML course websites with zero external build dependencies. It does not include confidential files, personal credentials, private API keys, or proprietary models.
